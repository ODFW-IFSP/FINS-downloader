# FINS
A repo that automatically pulls all historic Trapping and Spawning data from FINS for our FINS facilities: Lookingglass and Wallowa. Trapping data are downloaded daily at 6:30 PM PT. Spawning data are downloaded daily at 7:15 PM PT.

Direct URL links to the data:  
Trapping - https://github.com/ODFW-IFSP/FINS-downloader/raw/main/data/TrappingData.csv  
Spawning - https://github.com/ODFW-IFSP/FINS-downloader/raw/main/data/SpawningData.csv
